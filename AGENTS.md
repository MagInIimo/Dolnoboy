# Дальнобой по России / Trucking Across Russia

Перед любой работой полностью прочитать `C:\YandexGames\AGENTS.md` и перечисленные там документы. Родительские инструкции обязательны. Рабочие исходники: `game/`; финальный архив: `ready/`; проверки: `tmp/`; источники, лицензии и отчеты: `store/`. Дополнительно прочитать `SPEC.md`. Не включать инструкции и инструменты в архив.

Автоматические браузерные проверки этой игры выполнять только headless. Ильвир пожаловался на постоянно всплывающие тестовые окна Edge. Не запускать видимые отдельные окна Edge/Chrome и не активировать их для замеров. Старые headed-скрипты в `tmp/` — исторические материалы, их не запускать. Игру показывать во встроенном браузере Codex на обычном адресе `http://127.0.0.1:8787/`; тестовые страницы и фоновые вкладки не выводить поверх работы. Своё тестовое окно закрывать через принадлежащий проверке browser/context; личные окна пользователя не закрывать. Производительность headless не называть FPS активного видимого окна.
