# Дальнобой по России / Trucking Across Russia

Браузерная 3D-игра о грузоперевозках по России. Техническое задание находится в `SPEC.md`.

- `game/` — текущие исходники, ресурсы и собранный `app.js`.
- `tools/` — сборка, локальный сервер и инструменты разработки.
- `ready/` — сохранённый ZIP для Яндекс Игр.
- `store/` — история проверок и отчёты.
- `licenses/` — лицензии сторонних библиотек и ресурсов.

Временные файлы, браузерные профили, установленные зависимости и исторические ZIP из `store/` в репозиторий не включены.

## Локальный запуск

Из корня проекта в PowerShell:

```powershell
python.exe tools/server.py game 8787
```

Открыть `http://127.0.0.1:8787/`.

## Сборка

Нужны современный Node.js с npm и Python для локального сервера.

```powershell
npm ci --prefix tools
New-Item -ItemType Directory -Force tmp | Out-Null
node tools/build.mjs
```

Часть инструментов и отчётов относится к предыдущим версиям игры. ZIP в `ready/` сохранён отдельно и относится к предыдущему состоянию исходников; загрузка в GitHub не является новым релизом или проверкой готовности к модерации.
