# Конспект требований Яндекс Игр (для 3D-симулятора дальнобойщика)

Источник: https://yandex.ru/dev/games/doc/ru/concepts/requirements
Редакция страницы: «Дата последнего изменения: 29 сентября 2026 года». Снято 2026-10-03 (research-агент; полный текст сверен с локальным снимком `tmp/sources/yandex-requirements-2026-09-30.md`).
Метки: [УПРАЗДН.] — пункт упразднён; [РЕКОМЕНДАЦИЯ] — раздел 6, модерация не проверяет.

## Раздел 1. Технические требования
- 1.1 Встроен SDK Яндекс Игр.
- 1.2 Нет регистрации на сторонних сервисах; только Яндекс ID через SDK. 1.2.1 Авторизация только после осознанного действия. 1.2.2 Гостевая игра, прогресс сохраняется.
- 1.3 При потере фокуса звук останавливается.
- 1.4 Платежи только через SDK.
- 1.5 [УПРАЗДН.]
- 1.6.1 Мобильные: 1.6.1.1 полноэкранный режим; 1.6.1.2 клавиатура при вводе; 1.6.1.3–1.6.1.4 [УПРАЗДН.]; 1.6.1.5 полное управление жестами; 1.6.1.6 нет системного плеера; 1.6.1.7 нет уведомления о WebGL; 1.6.1.8 лонгтап не вызывает выделение/меню.
- 1.6.2 Десктоп: 1.6.2.1 поле до края области; 1.6.2.2 соотношение сторон поля не более 2:1; 1.6.2.3 [УПРАЗДН.]; 1.6.2.4 клавиатура/мышь, не зависит от раскладки; 1.6.2.5 нет системного плеера; 1.6.2.6 нет зарезервированных сочетаний; 1.6.2.7 нет выделения/контекстного меню.
- 1.6.3 ТВ (только если выбрано): пульт, Back/OK, без инапов, без ссылок.
- 1.7 Нет абсолютных URL на S3 Яндекса.
- 1.8 Интерактивные элементы адаптированы под экран.
- 1.9 Прогресс сохраняется сразу; переживает перезагрузку и поворот.
- 1.10 Ресайз/поворот: 1.10.1 нет обрезки; 1.10.2 нет браузерной прокрутки и swipe-to-refresh; 1.10.3 нет наложений; 1.10.4 управление одной рукой, всё нужное видно.
- 1.11 Облачные сохранения → включить опцию в черновике.
- 1.12 Подключена монетизация (реклама или инапы).
- 1.13 Инапы: 1.13.1 консумирование; 1.13.2 портальная валюта из SDK; 1.13.3 прогресс на сервере; 1.13.4 цена цифрами; 1.13.5 описание соответствует; 1.13.6 список совпадает с консолью.
- 1.14 Нет ошибок/зависаний при повороте, долгом нажатии, жестах, сворачивании, рекламе, навигации по истории.
- 1.15 Завершённый вид.
- 1.16 Нет модификаций и имитаций рекламных блоков.
- 1.17 [УПРАЗДН.]
- 1.18 Работа не ограничена URL.
- 1.19 SDK по документации: 1.19.1 инициализация; 1.19.2 LoadingAPI.ready(); 1.19.3 GameplayAPI.start/stop; 1.19.4 game_api_pause/resume.
- 1.20 Браузеры/ОС: Яндекс Браузер, Chrome, Firefox, Opera, Safari, приложение Яндекс; Android 5.0+, iOS 9.0+.
- 1.21 Не более 100 МБ в распакованном виде.
- 1.22 index.html в корне; в именах нет пробелов и кириллицы.
- 1.23 Запрещён интерактивный ИИ в играх; заранее сгенерированные материалы допустимы.
- 1.24 Обновление сохраняет концепцию.

## Раздел 2. Пользовательский опыт
- 2.1 Проработанность. 2.2 Управление описано в игре или в «Как играть». 2.3 Соответствие жанру. 2.4 Критерий механик. 2.5, 2.6 [УПРАЗДН.]. 2.7 Соответствие возрастному рейтингу. 2.8 Нарастающая сложность, понятный сеттинг. 2.9 Больше 10 минут или мотивация перепроходить. 2.10–2.12 [УПРАЗДН.]. 2.13 Рейтинг выше 30. 2.14 Автоопределение языка через SDK.

## Раздел 3. Содержание
- 3.1–3.3 [УПРАЗДН.].
- 3.4 Отсутствуют: 3.4.1 [УПРАЗДН.]; 3.4.2 чёрная магия; 3.4.3 реалистичное насилие/жестокость к животным, детям, пожилым; 3.4.4 политика, политические деятели, конфликты, войны; 3.4.5 религия, религиозные деятели и атрибуты; 3.4.6 предсказания о жизни и здоровье.
- 3.5 Авторские права у создателя.
- 3.6 Не копирует другие игры каталога.
- 3.7 Нельзя получить реальные деньги и ценности.
- 3.8 [УПРАЗДН.]. 3.9 Видео без выхода на внешние ресурсы.

## Раздел 4. Реклама
- 4.1 Только через SDK. 4.2 Процесс сохраняется после рекламы. 4.3 Ориентация рекламы = ориентация игры. 4.4 Только в логических паузах. 4.5 RV по желанию: 4.5.1 однозначная подпись рекламы и награды; 4.5.2 награда — бонус, не условие продолжения. 4.6 Доп. блоки — только стики-баннеры. 4.7 При fullscreen/RV звук и игра на паузе.

## Раздел 5. Описание и промоматериалы
- 5.1.1 Материалы из этой игры (5.1.1.1–5.1.1.3: 70% геймплея); 5.1.2 суть игры; 5.1.3 одинаковое название по языкам. 5.2 Обязательные поля. 5.3 Форматы. 5.4 Теги. 5.6 Иконка/обложка не скриншот. 5.9 Чёрный фон только если часть игры. 5.11 Без дублирования текстов. 5.12 Уникальное название. 5.5, 5.7, 5.8, 5.10 [УПРАЗДН.].

## Раздел 6. [РЕКОМЕНДАЦИИ]
- 6.1 e-mail; 6.2 отключение звука; 6.3 пауза; 6.4 нет ошибок в консоли; 6.5 без слова «игра»; 6.6 лаконичное название; 6.7 нет бесполезных кнопок; 6.8 обучение; 6.9 выбор языка иконкой и названиями на самих языках.

## Раздел 8. Тексты и медиаматериалы
- 8.2: орфография; соответствие механике; перевод; без мата; без запрещённых материалов.
- 8.3: качество без артефактов; суть объекта; без рамок/скруглений; без системного интерфейса и UI Яндекса; без эротики и оскорблений; безопасно для всех возрастов.

## Выводы для «Дальнобоя»
- Достопримечательности только светские: без храмов, куполов с крестами, мечетей, пагод, военных мемориалов, звёзд/гербов/флагов и памятников политикам.
- Реальных брендов и логотипов не использовать (риск по 3.5 и 8.2.2).
- Без звука через `<audio>/<video>` — только Web Audio. Без системного уведомления о WebGL: свой экран ошибки.
- Реклама: fullscreen только в паузах (после рейса), RV только с подписью «Реклама: +N ₽».
